# Supplementary Information
## Schumann-Proteostasis Coupling

### Contents
- S1_Appendix.pdf: Mathematical derivations and parameter sensitivity analysis
- S2_Code.zip: Complete Python source code for reproducibility
- S3_Data.zip: Processed simulation data (CSV files)

### How to Reproduce Results
1. Clone main repository: https://github.com/rikechacon/Schumann-Proteostasis-Coupling-SPC
2. Install dependencies: pip install -r requirements.txt
3. Run parametric sweep: python run_parametric_sweep.py
4. Generate figures: python generate_publication_figures.py
